## 📚 Content

### Overview of US Agricultural Data Sources

We survey the agencies and platforms that publish agriculture data used in this course.

Key points:

- USDA (NASS, NRCS, ERS)
- NOAA and NASA climate data
- State and regional data portals

<details>
<summary><strong>💬 Speaker Notes</strong></summary>

- Share which sources offer APIs vs bulk downloads
- Mention data cadence and update frequency

</details>

---

### Data Collection Methods and Formats

We compare how surveys, sensors, and remote sensing contribute to datasets.

Key points:

- Survey-based datasets and sampling limits
- Sensor data and real-time streams
- Remote sensing and derived products

<details>
<summary><strong>💬 Speaker Notes</strong></summary>

- Explain how collection method affects accuracy and bias
- Highlight that metadata often explains collection limitations

</details>

---

### File Formats and Access Patterns

We connect formats to workflows so students choose the right approach.

Key points:

- CSV, GeoJSON, Shapefile, GeoTIFF, NetCDF
- API access vs bulk downloads
- Licensing and attribution requirements

<details>
<summary><strong>💬 Speaker Notes</strong></summary>

- Mention that some portals require accounts or tokens
- Encourage students to document access steps

</details>

---

### Spatial Data Fundamentals

We cover the spatial concepts needed for later geospatial classes.

Key points:

- Coordinate reference systems and projections
- Vector vs raster data
- Spatial joins and alignment

## ✍️ Assignment

### Task: US Data Source Survey

**Objective:** Identify, access, and document high-value agricultural datasets for your region.

**Instructions:**
1. Select 3 to 5 relevant US agricultural data sources for your region.
2. Download a sample dataset from each source.
3. Document the access method, file format, and key metadata for each dataset.

**What to submit:** A short report with links, dataset notes, and citations.
