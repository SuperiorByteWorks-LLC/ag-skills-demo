### AI Fundamentals: Context Is Everything

**The Problem:**
- AI models don't remember previous conversations
- Each query starts fresh with no context
- Vague questions get vague answers

**The Solution:**
- Provide complete context every time
- Include: error message, code, requirements, expected outcome
- High-signal input → high-quality output

**Bad Example:**
```
"How do I fix this error?"
```

**Good Example:**
```
I'm trying to download Sentinel-2 satellite data for Iowa corn fields using the agri-data-toolkit script. 

Here's my code:
[paste code]

Here's the error:
[paste full error message]

I expected to download 5 tiles covering my study area, but I'm only getting 1 tile before the connection times out after 10 seconds.

What could be causing the timeout and how can I fix it?
```

**Why It Works:**
- Specific task (Sentinel-2 download)
- Context (Iowa corn fields, using specific script)
- Code and error included
- Expected vs actual behavior described
- Clear question

### AI Fundamentals: Retry with Different Models

**The Strategy:**
- If one model doesn't give a useful answer, try another
- Different models have different training and strengths
- One may catch bugs another misses

**Available Models:**
- GPT-4 (OpenAI)
- Claude (Anthropic)
- Gemini (Google)
- Open-source models (Llama, Mistral, etc.)

**When to Retry:**
- Answer seems generic or unhelpful
- Code suggestion doesn't work
- Explanation is unclear
- You're not confident in the response

**Best Practice:**
1. Try primary model (e.g., GPT-4)
2. If unsatisfied, switch to different model
3. Compare responses
4. Verify the best answer

**Temperature & Randomness:**
- Higher temperature = more creative/varied responses
- Lower temperature = more deterministic/consistent
- Can retry same model with different temperature
