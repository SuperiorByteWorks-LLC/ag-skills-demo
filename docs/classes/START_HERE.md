## 🎓 Common Questions Answered

### "Where do I start?"

→ Copy `TEMPLATE.md` and start replacing placeholder text.

### "How do I know if I'm doing it right?"

→ Use `STYLE_IMPLEMENTATION_CHECKLIST.md` while you work.

### "What if I don't understand the format?"

→ Look at `STYLE_REFERENCE_EXAMPLE.md` to see a complete example.

### "Where do I put images?"

→ In the `images/` folder with name: `class##_slide##_img##.png`

### "How long does this take?"

→ New class: 2-3 hours | Updating: 45 min - 1 hour | Converting PowerPoint: 3-5 hours

### "Can I use my own structure?"

→ No. The 9-section structure is required for consistency.

### "What if my class has extra content?"

→ Combine into the 9 sections or split into multiple classes.

### "How many learning outcomes should I have?"

→ 3-5. Specific, measurable, action-oriented.

### "What should the assignment look like?"

→ Clear objective + step-by-step instructions + deliverable + due date.

### "Who reviews my work?"

→ Use the checklist for self-review. Optional: peer review by colleague.

## 💡 Pro Tips

### Tip 1: Keep Template Open

Have `TEMPLATE.md` in one window and `STYLE_GUIDE.md` in another while writing.

### Tip 2: Fill in Order

Don't jump around. Fill sections in order:

1. Metadata
2. Housekeeping
3. Syllabus Review
4. Learning Outcomes ← Most important, do this carefully
5. Content
6. Assignment
7. Resources

### Tip 3: Images Improve Learning

If your PowerPoint has visuals, extract and include them. 2-5 images per class is ideal.

### Tip 4: Use Speaker Notes

Add HTML comment notes with teaching tips. Your future self will thank you.

### Tip 5: Test All Links

Before publishing, click every resource link. Broken links are a trust-killer.

### Tip 6: Get Feedback

Have a colleague review your first class. Notes help improve future ones.

### Tip 7: Update Metadata

Keep "Last Updated" current. Students appreciate knowing content is current.
