## Executive Summary

NOAA provides the longest-running and most comprehensive weather and climate observations in the United States. While NASA POWER offers gridded data globally, NOAA provides actual station observations that offer higher precision at specific locations.

**Key Facts:**

- **Data Type:** Time Series (CSV)
- **Temporal Resolution:** Daily, monthly
- **Coverage:** Global (30,000+ US stations)
- **Temporal Coverage:** 1763-present (varies by station)
- **Parameters:** Temperature, precipitation, wind, pressure, etc.
- **Access:** Free (API token required)
- **Update Frequency:** Daily

### Example 1: Find Nearest Station

```python
import requests
import pandas as pd
from math import radians, sin, cos, sqrt, atan2

def haversine(lat1, lon1, lat2, lon2):
    """Calculate distance between two points."""
    R = 6371  # km

    lat1, lon1, lat2, lon2 = map(radians, [lat1, lon1, lat2, lon2])
    dlat = lat2 - lat1
    dlon = lon2 - lon1

    a = sin(dlat/2)**2 + cos(lat1) * cos(lat2) * sin(dlon/2)**2
    c = 2 * atan2(sqrt(a), sqrt(1-a))

    return R * c

def find_nearest_station(lat, lon, stations_df):
    """Find nearest weather station."""
    stations_df = stations_df.copy()
    stations_df['distance'] = stations_df.apply(
        lambda r: haverside(lat, lon, r['latitude'], r['longitude']),
        axis=1
    )

    return stations_df.loc[stations_df['distance'].idxmin()]
```

### Example 2: Download Station Data

```python
import requests
import pandas as pd

def download_station_data(station_id, start_date, end_date, token):
    """
    Download daily weather data for a station.
    """
    url = f"https://www.ncei.noaa.gov/cdo-web/api/v2/data"

    params = {
        "datasetid": "GHCND",
        "stationid": station_id,
        "startdate": start_date,
        "enddate": end_date,
        "datatypeid": ["TMAX", "TMIN", "PRCP"],
        "units": "metric",
        "limit": 1000
    }

    headers = {"token": token}

    all_data = []
    offset = 1

    while True:
        params['offset'] = offset
        response = requests.get(url, headers=headers, params=params)
        data = response.json()

        if 'results' not in data:
            break

        all_data.extend(data['results'])

        if len(data['results']) < 1000:
            break

        offset += 1000

    # Convert to DataFrame
    df = pd.DataFrame(all_data)
    df['date'] = pd.to_datetime(df['date'])
    df = df.pivot(index='date', columns='datatypeid', values='value')

    return df

# Usage
weather = download_station_data(
    "GHCND:USC00130158",  # Example station
    "2023-01-01",
    "2023-12-31",
    "YOUR_TOKEN"
)
```

### Example 3: Calculate Climate Normals

```python
import pandas as pd
import numpy as np

def calculate_climate_normals(weather, period=(1991, 2020)):
    """
    Calculate 30-year climate normals.
    """
    # Filter to normal period
    normal_years = range(period[0], period[1]+1)
    normal_data = weather[weather.index.year.isin(normal_years)]

    # Monthly normals
    monthly = normal_data.resample('M').mean()

    # Growing season normals (April-October)
    growing_season = normal_data[
        (normal_data.index.month >= 4) &
        (normal_data.index.month <= 10)
    ]

    return {
        'monthly_normals': monthly,
        'growing_season_precip': growing_season['PRCP'].sum(),
        'growing_season_temp': growing_season[['TMAX', 'TMIN']].mean().mean()
    }
```

## Integration with NASA POWER

```python
# Compare station data with NASA POWER grid data
def compare_power_vs_station(power_data, station_data):
    """
    Validate NASA POWER against actual station observations.
    """
    # Match dates
    common_dates = power_data.index.intersection(station_data.index)

    power = power_data.loc[common_dates]
    station = station_data.loc[common_dates]

    # Calculate correlation
    correlation = power.corr(station)

    # Calculate bias
    bias = (power - station).mean()

    return {
        'correlation': correlation,
        'bias': bias
    }
```

## Strengths and Limitations

### Strengths

- **Actual observations** - Real measurements, not models
- **Long history** - 1763-present
- **Station-level precision** - Point data
- **Quality controlled** - NOAA quality flags

### Limitations

- **Sparse network** - Not all areas have stations
- **Missing data** - Gaps common in historical records
- **API token required** - Registration needed
- **Not global** - Focus on US
