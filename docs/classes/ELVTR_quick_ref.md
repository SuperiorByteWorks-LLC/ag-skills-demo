# ELVTR PPTX Style Guide - Quick Reference

## 🎨 COLOR PALETTE

### PRIMARY BRAND COLORS

```
#2D5016  - Dark Green (Titles, Primary Elements)
#4CAF50  - Medium Green (Accent Bar, Highlights)
#E8F5E9  - Light Green (Text on Dark Backgrounds)
```

### SECONDARY COLORS

```
#1E88E5  - Blue (Secondary Headings, Data)
#F57C00  - Orange (Warm Accent, Emphasis)
```

### NEUTRALS

```
#FFFFFF   - White (Main Background)
#F5F5F5   - Light Gray (Alternate Rows)
#212121   - Dark Gray (Primary Text)
#666666   - Medium Gray (Secondary Text)
#DDDDDD   - Light Border
```

## 🎬 THE 6 SLIDE TYPES

### 1️⃣ TITLE SLIDE

- Gradient: #2D5016 → #4CAF50
- Text: #FFFFFF (title), #E8F5E9 (subtitle)
- Centered, full-screen background

### 2️⃣ CONTENT SLIDE

- Background: #FFFFFF
- Title: #2D5016 (dark green)
- Text: #212121 (dark gray)
- Accent bar: #4CAF50 (5pt top)
- Max 5 bullets

### 3️⃣ TWO-COLUMN

- Background: #FFFFFF
- Title: #2D5016
- Left Col BG: #F5F5F5
- Right Col BG: #FFFFFF
- Headers: #1E88E5
- Accent bar: #4CAF50

### 4️⃣ DATA CHART

- Background: #FFFFFF with #EEEEEE grid
- Title: #2D5016
- Series 1: #1E88E5 (blue)
- Series 2: #F57C00 (orange)
- Series 3: #4CAF50 (green)
- Series 4: #D32F2F (red)
- Series 5: #9C27B0 (purple)

### 5️⃣ CALL-TO-ACTION

- Background: #2D5016 gradient
- Text: #FFFFFF
- Accent: #4CAF50 or #F57C00
- No top bar (full background)

### 6️⃣ DATA TABLE

- Header BG: #1E88E5, Text: #FFFFFF
- Row 1 BG: #FFFFFF
- Row 2 BG: #F5F5F5 (alternating)
- Borders: #DDDDDD
- Text: #212121

## 🎨 DESIGN ELEMENTS

**Top Accent Bar**

- Position: Top of content slides
- Height: 5px
- Color: #4CAF50
- Always include (except title/CTA slides)

**Callout Box**

- Background: #F5F5F5
- Border: 3px left #4CAF50
- Radius: 4-6px
- Padding: 20px
- Text: #212121

**Margins & Spacing**

- Horizontal margins: 48pt
- Vertical margins: 36pt
- Between sections: 24-36pt
- Between bullets: 12-16pt
- Line spacing: 1.3-1.4
