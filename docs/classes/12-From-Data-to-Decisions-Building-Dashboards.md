## 📚 Content

### Data Storytelling Fundamentals

We define how to turn data into narratives that guide action.

Key points:

- Audience needs and decision context
- Selecting metrics that matter
- Structuring a story: problem, evidence, action

<details>
<summary><strong>💬 Speaker Notes</strong></summary>

- Use a quick example of a weak vs strong story
- Emphasize clarity and brevity

</details>

---

### Dashboard Design Principles

We apply visual hierarchy and UX basics to dashboard design.

Key points:

- Layout and spacing for readability
- Color usage for emphasis
- Consistent chart types and labels

<details>
<summary><strong>💬 Speaker Notes</strong></summary>

- Mention that accessibility and contrast matter
- Encourage consistent units and legends

</details>

---

### Python BI Tools (Streamlit, Plotly Dash)

We compare tools and pick the right option for the project scope.

Key points:

- Streamlit for fast prototypes
- Plotly Dash for fine-grained control
- Deployment considerations

<details>
<summary><strong>💬 Speaker Notes</strong></summary>

- Encourage students to start with Streamlit if new to dashboards
- Note that deployment requirements may affect tool choice

</details>

---

### Interactive Visualizations and Real-Time Data

We discuss how to add interactivity and live updates to dashboards.

Key points:

- Filters, drill-downs, and tooltips
- Refresh intervals and caching
- Data reliability for live feeds

<details>
<summary><strong>💬 Speaker Notes</strong></summary>

- Ask students to define the minimum real-time requirement
- Remind them to avoid overwhelming users with too much interactivity

</details>

---

### Workshop: Build a Farm Dashboard

Students sketch and prototype a simple dashboard with core metrics.

Key points:

- Choose a story and primary audience
- Build a minimal set of visuals
- Identify follow-up improvements

<details>
<summary><strong>💬 Speaker Notes</strong></summary>

- Encourage students to prioritize insight over volume
- Suggest collecting feedback from peers

</details>

### Demo: Complete Dashboard Application

We demonstrate an end-to-end dashboard using real agricultural data.

Key points:

- Data pipeline integration
