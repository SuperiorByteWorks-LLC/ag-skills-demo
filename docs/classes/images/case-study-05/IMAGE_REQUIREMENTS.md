# Image Requirements: Case Study 1.05 - Regional Agricultural Diversity

This document specifies image requirements for the Regional Agricultural Diversity case study slides and supporting materials.

---

## General Requirements

**Format Specifications:**

- **Resolution:** 1920x1080 pixels (16:9 aspect ratio)
- **File format:** PNG (preferred) or high-quality JPG
- **File size:** <500KB per image (for web performance)
- **Color mode:** RGB
- **Usage context:** Slide presentations, web viewing

**Attribution Requirements:**

- All images must include source attribution
- Prefer public domain, USDA, or Creative Commons licensed images
- Document license and attribution for each image

## Required Images (8 Total)

### Image 1: U.S. Agricultural Regions Map

**Purpose:** Show geographic distribution of the three major production regions  
**Content:** U.S. map highlighting Corn Belt, Great Plains, and Southeast regions  
**Specifications:**

- Color-coded regions (Corn Belt: orange/yellow, Great Plains: blue, Southeast: green)
- State boundaries visible
- Major cities for reference
- Legend clearly identifying regions
- Clean, professional cartographic style

**Suggested sources:**

- USDA ERS regional classification maps
- Create custom map using USDA ag census data
- USGS or EPA ecoregion maps adapted for agricultural focus

**Attribution template:**

```
Map: U.S. Agricultural Production Regions
Data source: USDA [Year] / Created for Agricultural Data Systems course
```

### Image 2: Corn Belt Landscape - Intensive Agriculture

**Purpose:** Visual representation of Corn Belt intensive crop production  
**Content:** Aerial or ground-level photo of Corn Belt cornfields  
**Specifications:**

- Show scale and intensity of production (large fields, modern equipment)
- Preferably aerial view showing field patterns
- Good crop condition (mid-season green)
- Tile drainage lines visible if possible (subtle linear features)
- Clear horizon showing flat topography

**Suggested sources:**

- USDA NRCS photo library
- Iowa State University Extension resources
- Unsplash/Pexels "Iowa farmland" or "cornfield aerial"
- NASA/USGS aerial imagery

**Attribution template:**

```
Photo: Corn Belt agricultural landscape, [Location]
Source: [USDA NRCS / Photographer] / [License] / [Year]
```

### Image 3: Great Plains Center Pivot Irrigation

**Purpose:** Illustrate irrigation-dependent agriculture and characteristic circular field patterns  
**Content:** Aerial view of center pivot irrigation systems creating circular fields  
**Specifications:**

- Multiple circular irrigated fields visible
- Contrast between irrigated (green) and non-irrigated (brown) areas if possible
- Shows scale of Great Plains agriculture
- Preferably includes multiple pivots to show pattern
- High-resolution satellite or aerial imagery

**Suggested sources:**

- NASA Earth Observatory (has excellent center pivot imagery)
- USGS EarthExplorer (Landsat or aerial imagery)
- Google Earth screenshots (with proper attribution)
- Kansas/Nebraska state agricultural photo libraries

**Attribution template:**

```
Aerial image: Center pivot irrigation, [Location, State]
Source: NASA Earth Observatory / Landsat [Year] / Public domain
```

### Image 4: Southeast Cotton Field

**Purpose:** Show cotton as distinctive Southeast crop  
**Content:** Cotton field showing cotton plants with open bolls (harvest-ready)  
**Specifications:**

- Cotton plants clearly identifiable (white fiber visible in open bolls)
- Field-level or slightly elevated view
- Good lighting showing cotton quality
- Preferably with equipment (cotton picker) if available
- Shows scale of Southeast cotton production

**Suggested sources:**

- Cotton Incorporated image library
- University of Georgia Extension resources
- USDA NRCS photo library (search "cotton production")
- Creative Commons agricultural photography

**Attribution template:**

```
Photo: Cotton production, Southeast U.S.
Source: [USDA / University Extension / Photographer] / [License] / [Year]
```

### Image 5: Regional Crop Diversity Comparison

**Purpose:** Visual comparison of crop types across regions  
**Content:** Three-panel image showing representative crops for each region  
**Specifications:**

- **Panel 1 (Corn Belt):** Corn and soybean fields
- **Panel 2 (Great Plains):** Wheat field (golden harvest-ready wheat)
- **Panel 3 (Southeast):** Cotton, peanuts, or diverse crop mix
- Consistent image style/quality across panels
- Labels identifying region and crop

**Suggested approach:**

- Create composite image from three separate photos
- Ensure similar perspective/scale across panels
- Use tools like Photoshop, GIMP, or Canva for composition
- Cite each source photo separately

**Attribution template:**

```
Composite image: Regional crop diversity
Panel 1: [Source for corn/soy image]
Panel 2: [Source for wheat image]
Panel 3: [Source for cotton/peanut image]
Created for Agricultural Data Systems course / [Year]
```

### Image 6: Soil Profile Comparison

**Purpose:** Show soil quality differences between regions  
**Content:** Three soil profiles side-by-side showing soil horizons  
**Specifications:**

- **Corn Belt (left):** Deep, dark Mollisol with thick A horizon
- **Great Plains (center):** Moderately developed soil profile
- **Southeast (right):** Weathered Ultisol with distinct red/orange color
- Each profile labeled with soil order and organic matter percentage
- Scale indicator (depth markers)
- Professional soil science photography

**Suggested sources:**

- USDA NRCS soil profile database
- State soil survey photos
- University soil science departments
- National Cooperative Soil Survey photo library

**Attribution template:**

```
Soil profile comparison:
Left: Mollisol, [Location] - USDA NRCS
Center: [Soil type], [Location] - USDA NRCS
Right: Ultisol, [Location] - USDA NRCS
Public domain
```

### Image 7: Technology Adoption Comparison Infographic

**Purpose:** Visualize technology adoption differences across regions  
**Content:** Bar chart or infographic showing precision ag adoption rates  
**Specifications:**

- Compare 3-4 key technologies (GPS guidance, yield monitors, VRT, farm management software)
- Three bars per technology (Corn Belt, Great Plains, Southeast)
- Color-coded by region (consistent with regional color scheme)
- Clear percentage labels on bars
- Data source citation included
- Professional infographic design

**Key data points to visualize:**

- GPS Guidance: Corn Belt 60-75%, Great Plains 80-90%, Southeast 35-55%
- Yield Monitors: Corn Belt 65-80%, Great Plains 50-70%, Southeast 30-50%
- Variable Rate Tech: Corn Belt 35-50%, Great Plains 30-50%, Southeast 15-30%

**Suggested approach:**

- Create custom infographic using data from case study
- Use tools like Canva, Adobe Illustrator, or Python matplotlib
- Cite USDA ARMS data as source

**Attribution template:**

```
Infographic: Regional Precision Agriculture Adoption Rates
Data source: USDA ARMS [Years], Academic literature compilation
Created for Agricultural Data Systems course / [Year]
```

## Image Usage Guidelines

### In Slide Deck (Class 01)

- Images support regional differentiation concepts
- Attribution in small text at bottom corner
- Ensure legibility when projected
- Test visibility in light and dark modes

### In Case Study Document

- Larger, more detailed images acceptable
- Full attribution directly below image
- Figure captions explaining significance
- Link to higher-resolution versions if available

### Accessibility Considerations

- Provide alt text for all images
- Color-blind friendly color schemes for maps/graphics
- Text size large enough to read
- Don't rely solely on color to convey information
